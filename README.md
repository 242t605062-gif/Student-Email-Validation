# Student Email Validation

## 📌 Project Overview

Student Email Validation is a mini project developed to validate student email addresses and check whether they follow the correct email format. It helps identify valid and invalid email addresses using predefined validation rules.

## 🎯 Objectives

- Validate student email addresses.
- Check email address formatting.
- Identify invalid email inputs.
- Improve data accuracy during student registration.
- Understand email validation techniques.

## ✨ Features

- Email format validation.
- Identification of valid and invalid email addresses.
- Simple and user-friendly interface.
- Clear validation results.

## ⚙️ How It Works

1. The user enters a student email address.
2. The system checks the email against predefined validation rules.
3. The system displays whether the email format is valid or invalid.

## 🧪 Example

| Email Address | Expected Result |
|---|---|
| student@example.com | Valid format |
| student@gmail.com | Valid format |
| student@ | Invalid format |
| student.example.com | Invalid format |

**Note:** A valid email format does not guarantee that the email account exists or belongs to a student.
